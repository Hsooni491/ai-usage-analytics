# Tableau dashboard guide

## 0. Ready-made workbook

**`tableau/AI_Usage_Analytics.twbx`** is a packaged workbook with the data inside. Double-click it to open in
Tableau Desktop or Tableau Public. It contains 10 sheets (Q1 to Q9) and 3 dashboards:

* **Executive Overview**: Tool Popularity, Usage Intensity, Countries, Tool Quality
* **Value Deep Dive**: Purpose Impact, Free vs Paid, Job Families, Productivity by Usage
* **Behind the Data**: Correlations, Data Quality

It is generated by `scripts/build_tableau_workbook.py` (re-run after the data changes). The workbook was
written by script, not saved from Tableau, so expect to tidy sizes, colours and labels once it is open.
The sections below describe how to build or extend the same views by hand, or point them at Databricks.
To switch a data source to Databricks: *Data → (source) → Replace Data Source*.

## 1. Connect to the data

| Option | When | How |
|---|---|---|
| **Databricks (recommended)** | Pipeline deployed to Databricks | Tableau → Connect → **Databricks**. Server hostname + HTTP path from your SQL warehouse → *Connection details*. Sign in with OAuth or a personal access token. Catalog `ai_usage`, schema `gold`. |
| **CSV files** | Local run / Tableau Public | Tableau → Connect → **Text file** → `tableau/data/fct_ai_usage.csv`, then add the other `mart_*.csv` files as separate data sources. |

Use **`fct_ai_usage`** for anything you want to slice freely; use the `mart_*` tables when you want the pre-computed answer.

## 2. Calculated fields (on `fct_ai_usage`)

```text
Recommend %          = SUM([Is Promoter]) / COUNT([User Id])
Net Recommend Score  = (SUM([Is Promoter]) - SUM([Is Detractor])) / COUNT([User Id])
Paid Users %         = SUM([Is Paid User]) / COUNT([User Id])
Hours Saved per Month= AVG([Time Saved Hours Per Week]) * 4.33
```
Format the % fields as percentages. On `Usage Band` → *Sort* → by field `Usage Band Order` (ascending).

## 3. Sheets (one per business question)

| # | Sheet | Source | Build |
|---|---|---|---|
| KPI | **Headline KPIs** | fct | Text tiles: COUNTD(User Id), AVG(Productivity Score), AVG(Satisfaction Score), AVG(Time Saved Hours Per Week), Recommend %. |
| Q1 | **Tool popularity** | mart_tool_performance | Bar: `ai_tool` on Rows, `users` on Columns, sorted desc. Stack colour = students vs professionals (or use fct with Color = User Type). Filter out `Unknown`. |
| Q2 | **Tool quality** | mart_tool_performance | Scatter: X = `avg_productivity`, Y = `avg_satisfaction`, Size = `users`, Label = `ai_tool`, Colour = `net_recommend_score` (diverging). |
| Q3 | **Purpose impact** | mart_purpose_impact | Side-by-side bars: `ai_purpose` × `user_type`, measure `avg_time_saved_hrs_week`. |
| Q4 | **Usage intensity → results** | fct | Line: `Usage Band` (sorted by order) on Columns; AVG(Productivity Score) and AVG(Time Saved Hours Per Week) on dual axis. Add a separate scatter of Usage Hours vs Time Saved with a trend line (r ≈ 0.90). |
| Q5 | **Free vs paid** | mart_plan_tier_value | Bars per `plan_tier`, split by `user_type`: avg_productivity, avg_satisfaction; tooltip shows `median_cost_per_hour_saved`. |
| Q6 | **Country map** | mart_country_summary | Filled map: `country` (geographic role Country), colour = `avg_productivity`, tooltip = users, top_ai_tool. Exclude `Unknown`. |
| Q7 | **Job families** | mart_segment_summary | Filter `segment_type` = profession_category. Heat-map: `segment_value` × `user_type`, colour = avg_time_saved_hrs_week. Make `segment_type` a parameter-driven filter to switch to education / age group / gender. |
| Q8 | **What drives what** | mart_metric_correlations | Heat-map: `metric_x` on Columns, `metric_y` on Rows, colour = `pearson_r` (diverging −1…1), label = pearson_r. |
| DQ | **Data quality** | mart_data_quality | Bar: `check_name` by `affected_rows`, colour = `check_type`. Shows the engineering work done on the raw file. |

## 4. Dashboards

1. **Executive overview**: KPI tiles on top, then Tool popularity, Usage intensity and Country map. Filters: User Type, Country, AI Tool (apply to all sheets using `fct_ai_usage`).
2. **Value deep dive**: Tool quality scatter, Purpose impact, Free vs paid, Job families.
3. **Behind the data**: Correlation heat-map and Data-quality chart, plus a text box describing the pipeline (CSV → PySpark bronze/silver → dbt gold on Databricks → Tableau).

Add a dashboard action: clicking a tool in *Tool popularity* filters the other sheets.

## 5. Key findings to put in captions

* **ChatGPT dominates** with 41% of users; Google Gemini (14%) and Microsoft Copilot (12%) follow.
* **Gemini and Claude have the best net-recommend scores** (about +49) despite smaller user bases; Meta AI is lowest (0).
* **More usage, more value:** users at 6+ h/day save ~14.5 h/week and score productivity 8.0, against ~1.9 h and 3.6 for <1 h/day (r = 0.90 between usage and time saved).
* **Writing (students) and office work (professionals)** save the most time per week (~7.5 h).
* **Paying doesn't buy satisfaction:** free users have a higher net-recommend score (~44) than Standard-plan users (14–28).
* Students and professionals look very similar on productivity (5.2 vs 5.3) and satisfaction (6.2 vs 6.1).
* The raw file needed real cleaning: 12 duplicate rows, units mixed into numbers ("2 hrs", "$1,884"), 17 spellings of AI tool names, and implausible outliers (age 97, 23 h/day of AI use).

> The sample is small (288 users), so treat segment results with fewer than ~10 users as indicative only.
